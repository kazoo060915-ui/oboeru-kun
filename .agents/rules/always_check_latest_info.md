# 最新情報の確認およびAIモデル・API指定の絶対厳守ルール

## 1. 古い知識での思い込み出力の禁止
- AIモデル名、API仕様、ライブラリのバージョンなどは、過去の学習データの思い込みで提示してはならない。
- 不明点や最新のバージョン情報がある場合は、必ず `search_web` やローカルの設定ファイル（`model_selection_guide.md` 等）を確認した上で最新情報を正確に提示すること。

## 2. アプリ内モデルIDの絶対指定ルール
- アプリコード（`lib/anthropic.ts` 等）で APIモデルIDを指定・書き換える時は、**必ず以下の3つのいずれか**を正確に使用すること。
  - `claude-haiku-4-5-20251001`（爆速）
  - `claude-sonnet-5`（高精度）
  - `claude-opus-5`（最高峰）
- それ以外の旧世代モデルID（3.5系等）は絶対に記述してはならない。
